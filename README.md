# n8n & AI Automation Projects 🚀

A hands-on learning repository documenting my journey of learning **n8n, workflow automation, AI agents, APIs, RAG, MCP, voice AI, and multi-agent systems**.

I am following a YouTube course and building each project myself instead of just watching the tutorials. This repository contains my implementations, workflow exports, documentation, experiments, and improvements.

## 📁 Project Structure

Each project will have its own folder containing the workflow, documentation, and related resources.

```text
Project-XX-Project-Name/
│
├── README.md
├── workflow.json
├── screenshots/
├── assets/
└── notes.md
```

### Folder Contents

| File / Folder   | Purpose                                                     |
| --------------- | ----------------------------------------------------------- |
| `README.md`     | Project description, workflow, setup instructions and usage |

| `screenshots/`  | Workflow screenshots and results                            |
